Condução Transiente 1D (MEF)

Sobre o problema

Resolvemos a equação da condução transiente de calor 1D usando Método dos Elementos Finitos com condutividade térmica variável k(x). Condições de contorno: T(0,t) = 0 e T(L,t) = 1. Condutividade: k(x) = k₁ para x < L/2 e k(x) = k₂ para x ≥ L/2 (configuráveis).

Método utilizado

Utilizamos o Método dos Elementos Finitos (MEF) com elementos lineares uniformemente espaçados e integração temporal via método de Crank-Nicolson. O número de elementos é configurável, demonstrando a flexibilidade do MEF para tratar condutividade térmica variável. A solução analítica mostrada é para k(x) constante (linha reta) como referência.
